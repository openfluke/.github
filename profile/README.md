# Openfluke

Open-source **Go AI / ML** — neural engines, GPU backends, and tooling.

## Flagship

**[Welvet](https://github.com/openfluke/welvet)** — Go AI engine: layers, quants / k-quants, and backends (CPU SIMD · WebGPU · CUDA · Metal · MLX · Vulkan · ROCm · QNN).

| Repo | Role |
|------|------|
| [welvet](https://github.com/openfluke/welvet) | Go engine |
| [welvet.cpp](https://github.com/openfluke/welvet.cpp) | CPU C++ + SIMD |
| [welvet.cuda](https://github.com/openfluke/welvet.cuda) | NVIDIA CUDA |
| [welvet.metal](https://github.com/openfluke/welvet.metal) | Apple Metal |
| [welvet.mlx](https://github.com/openfluke/welvet.mlx) | Apple MLX |
| [welvet.vulkan](https://github.com/openfluke/welvet.vulkan) | Vulkan |
| [welvet.rocm](https://github.com/openfluke/welvet.rocm) | AMD ROCm / HIP |
| [welvet.qnn](https://github.com/openfluke/welvet.qnn) | Qualcomm Hexagon / QNN |
| [w2a](https://github.com/openfluke/w2a) | Automated parity & tests |
| [octo](https://github.com/openfluke/octo) | Model shell (HF → ENTITY → run) |
